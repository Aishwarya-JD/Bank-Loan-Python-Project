# Bank Loan Analysis
**Overview:**

The Bank Loan Analysis project focuses on analyzing loan data to evaluate lending performance, borrower characteristics, repayment behavior, and portfolio risk. Using Python-based data analysis and visualization techniques, the project transforms raw financial data into meaningful insights that support strategic decision-making in the banking and financial services sector.

**Business Problem:**

Financial institutions process thousands of loan applications and must continuously monitor portfolio performance, repayment trends, and borrower risk. This project addresses these challenges by providing a comprehensive analysis of loan applications, funded amounts, repayments, and credit quality metrics.

**Project Objectives:**
Analyze overall loan portfolio performance.
Monitor loan application and funding trends.
Evaluate repayment behavior and loan quality.
Measure portfolio risk through good and bad loan metrics.
Identify regional and demographic lending patterns.
Generate actionable insights through data visualization.

**Dataset Information:**
The dataset contains 38,576 loan records and 24 attributes, including:
Loan Amount
Interest Rate
Loan Status
Annual Income
Debt-to-Income Ratio (DTI)
Employment Length
Loan Purpose
Home Ownership
Verification Status
Funding and Payment Information
Geographic Information (State-wise data)

**Dataset Size:** 38,576 Rows × 24 Columns.
